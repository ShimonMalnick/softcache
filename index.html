SoftCache

Adaptive Step Size Caching for Diffusion Transformers

Shimon Malnick1 Nadav Orenstein1 Ohad Fried2 Shai Avidan1
1Tel Aviv University   2Reichman University
arXivsoonCode

Training-free acceleration for diffusion transformers.

Diffusion models build an image or video by running a huge network dozens of times. SoftCache reuses the network's recent output instead of recomputing it, and takes bigger steps while that reuse is still accurate.

How it works

Caches decide when to refresh. SoftCache also decides how far to go: right after a refresh it jumps over several steps, then shrinks back as the next refresh nears.

Both samplers read the same staleness signal and refresh at the same kind of moment. The difference is what happens between refreshes. SeaCache walks the fixed grid one node at a time; SoftCache stretches the first cached steps after a refresh, when the headroom is largest, and lands between scheduled nodes. Fewer steps are taken for the same number of fresh passes, which is where the extra speed comes from.
